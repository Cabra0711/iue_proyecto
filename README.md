# IUE PROYECTO

Sistema de gestión de solicitudes de grado para la IUE (Universidad).

## Estructura
- `main.py` - Menú principal con login de estudiante y administrador
- `data/student_data.py` - CRUD de estudiantes
- `data/faculty.py` - CRUD de facultades
- `data/program.py` - CRUD de programas
- `data/storage.py` - Persistencia CSV
- `data/seed.py` - Datos iniciales
- `validators/request.py` - Gestión de solicitudes de grado
- `validators/auth.py` - Autenticación
- `reports/reports.py` - Reportes de graduandos
- `csv/` - Archivos CSV de datos
